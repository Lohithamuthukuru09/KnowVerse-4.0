Unit 3 · Classification and Prediction
🧩

1. Issues Regarding Classification and Prediction

The challenges of learning from examples

Classification assigns a record to a category (such as spam or not spam). Prediction estimates an unknown or future value (such as tomorrow's temperature). A model learns patterns from training data and uses them on new data.

Important issues

  • Data quality: missing, noisy or incorrect values can mislead a model.
  • Overfitting: the model memorizes training examples and performs poorly on new data.
  • Underfitting: the model is too simple to learn important patterns.
  • Speed and scalability: large datasets need efficient algorithms.
  • Interpretability: people may need to understand why a model made a decision.
  • Class imbalance: rare classes can be overlooked if most examples belong to another class.
Real-world example: A hospital model trained mostly on records from adults may not make reliable predictions for children. The training data must represent the people the model will serve.
🌳

2. Classification by Decision Tree Induction

A flowchart-like model that asks a sequence of questions

A decision tree is a tree-shaped model. The root node contains the first test, branches represent test outcomes, and leaf nodes give the predicted class. During induction, the algorithm selects useful attributes to split the training data into purer groups.

How it is built

  • Start with all training records at the root.
  • Choose a splitting attribute using a measure such as Information Gain or Gini Index.
  • Split records into child nodes and repeat.
  • Stop when a node is sufficiently pure or a stopping rule is met; prune branches if needed to reduce overfitting.
Real-world example: A loan approval tree might ask: “Is income above a threshold?” then “Is the credit history good?” The path leads to an approval prediction. Actual lending decisions require careful fairness and legal checks.
🎲

3. Bayesian Classification

Classification using probability and Bayes' theorem

Bayesian classifiers use probability to estimate which class is most likely for a given set of features. Naive Bayes is a popular method that assumes features are conditionally independent given the class. This assumption is not always true, but the method can still work well.

Real-world example: An email filter estimates whether an email is spam using clues such as words, sender and links. It compares the probability of spam with the probability of not spam.

Bayes' theorem

P(Class | Evidence) = P(Evidence | Class) × P(Class) ÷ P(Evidence)
  • Prior: probability of a class before seeing the evidence.
  • Likelihood: probability of the evidence if the class is true.
  • Posterior: updated probability after considering the evidence.
🧠

4. Classification by Backpropagation

How an artificial neural network learns from its mistakes

Backpropagation is a learning algorithm used to train multilayer neural networks. The network makes a prediction, calculates the error using a loss function, then sends information about that error backward through the network to calculate how weights should change.

Learning cycle

  • Forward pass: inputs travel through the network to produce an output.
  • Loss calculation: compare the output with the correct answer.
  • Backward pass: calculate gradients using the chain rule.
  • Weight update: an optimizer such as gradient descent adjusts weights; repeat over many examples.
Real-world example: Imagine teaching a network to recognize handwritten digits. If it predicts “8” when the image shows “3”, the error is used to adjust the network so future predictions can improve.
↔️

5. Support Vector Machines (SVM)

Finding a boundary that separates classes

A Support Vector Machine is a supervised learning method commonly used for classification. It searches for a decision boundary (a hyperplane) that separates classes while maximizing the margin between the boundary and the closest training points. Those closest points are called support vectors.

Real-world example: Suppose a model separates two kinds of flowers using petal length and width. SVM tries to find a boundary that leaves the widest possible gap between the two groups.
  • Linear SVM: uses a straight boundary (in two dimensions).
  • Kernel SVM: can model more complex boundaries by using a kernel function.
  • Key idea: the margin and support vectors determine the separating boundary.
🧰

6. Other Classification Methods

Different tools for different data problems

Decision trees, Bayesian methods, neural networks and SVMs are not the only choices. Other commonly used classification methods include:

  • k-Nearest Neighbors (k-NN): assigns a class based on the classes of nearby examples.
  • Rule-based classification: uses IF–THEN rules to assign classes.
  • Random forests: combines many decision trees and aggregates their predictions.
  • Logistic regression: estimates class probabilities, often for binary classification.
  • Ensemble methods: combine multiple models to improve performance or stability.
Real-world example: A plant-identification app might compare a leaf's features with nearby labelled examples using k-NN, or combine many trees in a random forest.
🔮

7. Prediction

Estimating a value rather than choosing a category

In data mining, prediction often means estimating a continuous numeric value. Regression is a common prediction approach. A model learns the relationship between input variables and a target value, then estimates the target for new cases.

Real-world example: A house-price model may use area, location, age and number of rooms to estimate a selling price. The result is a number, not a label such as “yes” or “no”.
  • Choose relevant input features and a target value.
  • Train the model using historical examples.
  • Evaluate prediction errors on unseen data.
  • Use the trained model to estimate values for new cases.
🎯

8. Classifier Accuracy

Checking whether a classifier makes reliable predictions

Classifier evaluation measures how well predicted classes match the true classes. Accuracy is the proportion of all predictions that are correct, but it should not be used alone when classes are imbalanced.

Accuracy = (True Positives + True Negatives) ÷ Total Predictions
  • Precision: among predicted positives, how many are truly positive?
  • Recall: among actual positives, how many did the model find?
  • F1-score: harmonic mean of precision and recall.
  • Confusion matrix: summarizes correct and incorrect predictions by class.
Real-world example: If 95 out of 100 predictions are correct, accuracy is 95%. But if only 5 cases are dangerous and the model misses all 5, accuracy alone hides a serious problem. Recall matters too.
